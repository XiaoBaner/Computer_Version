# 真人录音包：从十句录音到项目音色

目标：用一位真人（同学即可）录 20 句，做出一个**音色稳定、演法是人**的项目音色，用来替代现在几版 TTS 合成声。

为什么走这条：克隆只能搬音色，搬不动演法。做作、情感不连续这两个毛病，出在演法上，只有真人能解。

---

## 1. 找谁录

- 一位女生，普通话标准，声音偏中低、不尖（**不是**要播音腔，日常说话的自然感更重要）
- 时间成本：20 句 × 2 遍，约 15 分钟
- 需要她签一句授权（见 §5），写明用途是课程项目、模型合成、公开展示

## 2. 录音环境与设备

| 项 | 要求 |
| --- | --- |
| 房间 | 小房间，有窗帘/衣柜/床这类软装。不要卫生间（混响重）、不要空旷教室 |
| 噪音 | 关空调、关风扇、手机静音。录前静音 5 秒，方便后面对噪声底 |
| 设备 | 手机自带录音即可；有线耳机麦更好。**不要**用扬声器外放录音 |
| 距离 | 嘴到麦 10–15 cm，略偏 45°，避免喷麦 |
| 格式 | 任意，最好 48 kHz 单声道 WAV；mp3 也行（320 kbps） |
| 姿势 | 坐着，别晃，别用手碰麦 |

## 3. 台词稿（20 句）

分五组，覆盖项目里真实会出现的语气。**每句录两遍**，第二遍允许换一种说法，两遍里挑更好的那条。

### A. 打招呼 / 开场（平稳、不热情过头）
1. 嗯，我在。
2. 你来了。今天想从哪儿说起都行。
3. 不着急，慢慢说。

### B. 确认 / 澄清（句尾下沉，不要上扬成疑问腔）
4. 你是说，导师那句话让你觉得自己被否定了？
5. 我确认一下，是这周三发生的事，对吗？
6. 所以你现在最难受的，不是那件事本身，是没人问过你的感受。

### C. 安抚（气声多一点，语速比正常慢一成）
7. 听起来今天挺累的。
8. 被那样说，心里肯定不好受。
9. 你不用马上回答。想说的时候，我都在。
10. 这件事不怪你。
11. 能撑到现在，已经很不容易了。

### D. 陪伴 / 推进（自然、有停顿）
12. 要不要先跟我说说，最烦的是哪一件事？
13. 我们先做一次深呼吸。慢慢来，不着急。
14. 如果明天只能解决一件小事，你想先解决哪件？
15. 你刚才说到导师，停了一下。是他说了什么吗？

### E. 收束 / 结束（轻，不要突然变亮）
16. 今天先到这儿。你说的这些，我都记着。
17. 那就这样，早点休息。
18. 下次想说的时候，随时来找我。
19. 我一直在这儿。
20. 晚安。

> 录的时候不用刻意"演温柔"。按平时跟朋友说话的口气说就行——**刻意演出来的温柔，就是现在几版合成声听起来做作的原因**。

## 4. 录完之后

1. 把整段录音裁成单句：`python3 tools/voice/segment_takes.py --audio <录制文件> --out <输出目录>`
   （按静音自动切分，切完人工听一遍，删掉读错的、咳嗽的）
2. 归一化到 −20 dBFS RMS、峰值 ≤ −1 dBFS：
   `python3 tools/voice/normalize_wav.py <目录>/*.wav --out <目录> --force`
3. 挑 1 条 5–10 秒、语气自然的当参考音，其余留作微调数据
4. 克隆验证：
   ```
   ~/.cache/qwen3tts-venv3/bin/python tools/voice/lock_voice.py \
     --model-dir ~/.cache/modelscope/models/Qwen--Qwen3-TTS-12Hz-1.7B-Base/snapshots/master \
     --ref-audio <参考音.wav> --ref-text "<参考音对应台词>" \
     --plan-json assets/voice/demos/refsweep-lines.json \
     --out assets/voice/demos/<名字> --device mps
   ```

## 6. 验收标准

录完先过三关，不过就重录：

- [ ] 底噪听得见但不明显（安静房间里应有轻微环境声，不是死寂）
- [ ] 没有爆音、没有喷麦的"噗"声
- [ ] 同一句话两遍里，至少一遍听起来像"随口说的"，不是"念出来的"
